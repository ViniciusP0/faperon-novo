# Zétele (assistente de IA do site) — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Colocar o Zétele no canto inferior direito do Início e da Central: um assistente que responde só sobre o site, com perguntas prontas, números do IBGE consultados por ferramentas e conferidos em código.

**Architecture:** App Django novo `zetele` (endpoints `GET /api/v1/zetele/estado` e `POST /api/v1/zetele/perguntar`) com laço manual de tool use sobre o Sonnet 5.5, ferramentas que chamam os serviços determinísticos já existentes, conferência de números/links/idioma antes de entregar e registro anônimo das perguntas. No Next, o proxy passa a repassar `POST` e um widget client (`components/zetele/`) é montado no layout raiz e só aparece em 4 rotas.

**Tech Stack:** Django 5.2 + DRF, SDK `anthropic==1.15.0`, Postgres 16, Next.js 15 + React 19, Tailwind 3, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-17-zetele-design.md` (leia antes de cada tarefa).

## Global Constraints

- Branch de trabalho: `feat/zetele`. Nada vai para `main` sem pedido explícito (push em `main` faz deploy na vinicin).
- Modelo do bot: `claude-sonnet-5-5`. SDK fixado: `anthropic==1.15.0`.
- Chamada ao modelo: `thinking={"type": "adaptive"}`, `output_config={"effort": "low", "format": FORMATO}`, `tool_choice` só `auto` (ou `none` na última rodada); nunca `any`/`tool` (400 no Sonnet 5.5); ferramentas com `strict: True` e `additionalProperties: False`; `betas=["server-side-fallback-2026-07-01"]` + `fallbacks: "default"`; cliente com `timeout=20.0`, `max_retries=1`; `max_tokens=1500`.
- Laço: no máximo 3 rodadas, 4 chamadas de ferramenta, 40 s de orçamento total.
- Limites: `6/min` por IP (`zetele`), `30/min` global (`zetele_global`), `1500` perguntas/dia, `3` simultâneas por processo.
- Entrada: pergunta de 1 a 500 caracteres; histórico de até 6 mensagens, cada uma com até 1.200 caracteres; `pagina` em `/`, `/central-de-inteligencia`, `/central-de-inteligencia/observatorio`, `/painel`.
- Registro: só texto mascarado, status, página, data e tokens. **Nunca** IP, user agent, resposta ou id de conversa. Expurgo após 90 dias.
- A chave `ANTHROPIC_API_KEY` fica só no `.env.local` (fora do git). Nunca imprimir, logar ou commitar a chave. O `.env.example` não tem a chave.
- Nenhum teste fala com a Anthropic de verdade, exceto os marcados `@pytest.mark.llm` (excluídos por padrão).
- Textos de interface em português do Brasil, sem emoji. Regex sobre texto em português no TypeScript usa `(?<!\p{L})…(?!\p{L})` com a flag `u`, nunca `\b`; em Python, `(?<![^\W\d_])…(?![^\W\d_])`.
- Estilo do repo: Python com type hints, ruff (`line-length = 100`) e mypy limpos; TypeScript estrito, ESLint limpo; comentários curtos em português explicando o porquê.
- Comandos do backend rodam no container com o código montado (o `api-dev` não monta `apps/api` sozinho):
  `docker compose run --rm -v "$PWD/apps/api:/app" api-dev <comando>` a partir da raiz do repo. Abaixo, isso é abreviado como **`$API`** (ex.: `$API pytest tests/test_x.py -v`).
- Comandos do front rodam em `apps/web` (`npm test`, `npm run lint`, `npm run typecheck`).
- Commits terminam com a linha `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

```python
"""Grava a pergunta mascarada. Nunca guarda IP nem a resposta (ADR 0030)."""

import logging
import re

from django.db import DatabaseError

from zetele.models import Pergunta

log = logging.getLogger(__name__)

REMOVIDO = "[removido]"
# Ordem importa: e-mail antes de números; CNPJ antes de CPF (o CPF casaria dentro do CNPJ).
_PADROES = [
    re.compile(r"[\w.+-]+@[\w-]+(?:\.[\w-]+)+"),
    re.compile(r"\d{2}\.?\d{3}\.?\d{3}/?\d{4}-?\d{2}"),
    re.compile(r"\d{3}\.?\d{3}\.?\d{3}-?\d{2}"),
    re.compile(r"\(?\d{2}\)?\s?9?\d{4}-?\d{4}"),
    re.compile(r"\d{8,}"),
]


def mascarar(texto: str) -> str:
    for padrao in _PADROES:
        texto = padrao.sub(REMOVIDO, texto)
    return texto[:500]


def registrar(
    texto: str, status: str, pagina: str, tokens_entrada: int = 0, tokens_saida: int = 0
) -> None:
    """Falha ao gravar não derruba a resposta ao visitante."""
    try:
        Pergunta.objects.create(
            texto=mascarar(texto),
            status=status,
            pagina=pagina[:64],
            tokens_entrada=tokens_entrada,
            tokens_saida=tokens_saida,
        )
    except DatabaseError:
        log.exception("zetele: falha ao registrar a pergunta")
```

`apps/api/zetele/expurgo.py`:

```python
"""Perguntas do Zétele vivem 90 dias (ADR 0030); o scheduler apaga o resto a cada passada."""

from datetime import datetime, timedelta

from django.utils import timezone

from zetele.models import Pergunta

RETENCAO = timedelta(days=90)


def limite_expurgo(agora: datetime) -> datetime:
    return agora - RETENCAO


def expurgar_perguntas(agora: datetime | None = None) -> int:
    apagadas, _ = Pergunta.objects.filter(
        criada_em__lt=limite_expurgo(agora or timezone.now())
    ).delete()
    return apagadas
```

import csv
from datetime import timedelta
from typing import Any

from django.core.management.base import BaseCommand
from django.utils import timezone

from zetele.models import Pergunta


class Command(BaseCommand):
    help = "Imprime em CSV as perguntas feitas ao Zétele nos últimos N dias (base do FAQ)."

    def add_arguments(self, parser: Any) -> None:
        parser.add_argument("--dias", type=int, default=90)

    def handle(self, *args: Any, **opts: Any) -> None:
        desde = timezone.now() - timedelta(days=opts["dias"])
        escritor = csv.writer(self.stdout)
        escritor.writerow(["texto", "status", "pagina", "criada_em"])
        for p in Pergunta.objects.filter(criada_em__gte=desde).order_by("criada_em"):
            escritor.writerow([p.texto, p.status, p.pagina, p.criada_em.isoformat()])

"""Confere a resposta do modelo antes de entregar: números, links e idioma (ADR 0029).

Todo número do texto precisa existir nos resultados das ferramentas, na base de conhecimento ou na
própria conversa. Links só para rotas reais e para as URLs que as ferramentas devolveram.
"""

import re
from collections.abc import Iterable
from dataclasses import dataclass
from decimal import Decimal
from typing import Any
from urllib.parse import urlsplit

from django.conf import settings

ROTAS_PERMITIDAS = frozenset(
    {
        "/",
        "/central-de-inteligencia",
        "/central-de-inteligencia/observatorio",
        "/painel",
        "/sobre",
        "/informativos-tecnicos",
        "/noticias",
        "/fale-conosco",
        "/ipagro",
        "/sindicatos-rurais",
        "/comissao-mulheres",
        "/politica-de-privacidade",
    }
)
HOSTS_EXTERNOS = frozenset(
    {"sidra.ibge.gov.br", "www.faperon.com.br", "sistemafaperon.org.br", "www.cnabrasil.org.br", "wa.me"}
)
# Palavras inglesas comuns que não existem em português: sinal de raciocínio vazado em inglês
# (um bot já trocou "camisinha" por "condomínio" passando por "condom").
PALAVRAS_EM_INGLES = ("the", "with", "from", "which", "this", "and", "you", "your", "condom")
# Contagens pequenas ("os 5 maiores") passam sem fonte; porcentagens nunca.
PEQUENOS = frozenset(str(n) for n in range(11))

RE_NUMERO = re.compile(r"(?<![\d.,])(\d{1,3}(?:\.\d{3})+(?:,\d+)?|\d+(?:,\d+)?)(?!\d)(\s?%)?")
RE_LINK_MD = re.compile(r"\[([^\]]+)\]\(([^)\s]+)\)")
RE_URL_SOLTA = re.compile(r"(?<!\]\()https?://[^\s)\]]+")
_LETRA = r"[^\W\d_]"


def _canonico(valor: Decimal) -> str:
    texto = format(valor.normalize(), "f")
    return "0" if texto in {"-0", ""} else texto


def normalizar(token: str) -> str:
    return _canonico(Decimal(token.replace(".", "").replace(",", ".")))


def numeros_permitidos(fontes: Iterable[Any]) -> set[str]:
    permitidos: set[str] = set()

    def visitar(valor: Any) -> None:
        if isinstance(valor, bool) or valor is None:
            return
        if isinstance(valor, int | float | Decimal):
            permitidos.add(_canonico(Decimal(str(valor))))
        elif isinstance(valor, str):
            permitidos.update(normalizar(m.group(1)) for m in RE_NUMERO.finditer(valor))
        elif isinstance(valor, dict):
            for item in valor.values():
                visitar(item)
        elif isinstance(valor, list | tuple | set):
            for item in valor:
                visitar(item)

    for fonte in fontes:
        visitar(fonte)
    return permitidos


def _link_permitido(url: str, urls_ferramentas: set[str]) -> bool:
    if url.startswith("/"):
        partes = urlsplit(url)
        if partes.query:
            return url in urls_ferramentas
        return partes.path in ROTAS_PERMITIDAS
    partes = urlsplit(url)
    return partes.scheme == "https" and partes.hostname in HOSTS_EXTERNOS


def limpar_links(texto: str, urls_ferramentas: set[str]) -> tuple[str, int]:
    """Link reprovado vira só o texto (Markdown) ou some (URL solta). Não derruba a resposta."""
    removidos = 0

    def markdown(m: re.Match[str]) -> str:
        nonlocal removidos
        if _link_permitido(m.group(2), urls_ferramentas):
            return m.group(0)
        removidos += 1
        return m.group(1)

    def solta(m: re.Match[str]) -> str:
        nonlocal removidos
        url = m.group(0).rstrip(".,;:")
        resto = m.group(0)[len(url) :]
        if _link_permitido(url, urls_ferramentas):
            return m.group(0)
        removidos += 1
        return resto

    texto = RE_LINK_MD.sub(markdown, texto)
    texto = RE_URL_SOLTA.sub(solta, texto)
    return texto, removidos


def _termos_proibidos(texto: str) -> list[str]:
    termos = [*PALAVRAS_EM_INGLES, *settings.ZETELE_TERMOS_BLOQUEADOS]
    return [
        t
        for t in termos
        if re.search(rf"(?<!{_LETRA}){re.escape(t)}(?!{_LETRA})", texto, re.IGNORECASE)
    ]


@dataclass(frozen=True)
class Verificacao:
    aprovada: bool
    texto: str
    motivos: tuple[str, ...]
    links_removidos: int


def verificar(
    texto: str, *, dados: Iterable[Any], referencias: Iterable[str], urls_ferramentas: set[str]
) -> Verificacao:
    limpo, removidos = limpar_links(texto, urls_ferramentas)
    permitidos = numeros_permitidos([*dados, *referencias])
    # números dentro de URLs (ano no filtro, tabela do SIDRA, WhatsApp) não são afirmações
    sem_links = RE_URL_SOLTA.sub(" ", RE_LINK_MD.sub(r"\1", limpo))
    motivos: list[str] = []
    for m in RE_NUMERO.finditer(sem_links):
        token, porcentagem = m.group(1), m.group(2)
        n = normalizar(token)
        if n in permitidos or (not porcentagem and n in PEQUENOS):
            continue
        motivos.append(f"número sem fonte: {token}")
    motivos.extend(f"termo proibido: {t}" for t in _termos_proibidos(limpo))
    return Verificacao(not motivos, limpo, tuple(motivos), removidos)

"""De onde o Zétele tira o que sabe sobre o site. Hoje: o site.md inteiro no prompt.

A interface já é a do RAG futuro (BaseVetorial com pgvector, BaseFaq): trocar a fonte não mexe no
agente nem no prompt.
"""

import re
from pathlib import Path
from typing import Protocol, TypedDict

ARQUIVO = Path(__file__).parent / "conhecimento" / "site.md"
RE_SECAO = re.compile(r"^## \[([^\]]*)\] (.+)$", re.MULTILINE)


class Trecho(TypedDict):
    titulo: str
    rota: str | None
    texto: str


class FonteDeConhecimento(Protocol):
    def trechos(self, pergunta: str, limite: int) -> list[Trecho]: ...


def ler_secoes(texto: str) -> list[Trecho]:
    marcas = list(RE_SECAO.finditer(texto))
    trechos: list[Trecho] = []
    for i, m in enumerate(marcas):
        fim = marcas[i + 1].start() if i + 1 < len(marcas) else len(texto)
        rota = m.group(1).strip()
        trechos.append(
            Trecho(
                titulo=m.group(2).strip(),
                rota=rota if rota.startswith("/") else None,
                texto=texto[m.end() : fim].strip(),
            )
        )
    return trechos


def texto_da_base() -> str:
    return ARQUIVO.read_text(encoding="utf-8")


class BaseEstatica:
    """Devolve todas as seções, na ordem do arquivo; ignora a pergunta."""

    def __init__(self, caminho: Path = ARQUIVO) -> None:
        self._trechos = ler_secoes(caminho.read_text(encoding="utf-8"))

    def trechos(self, pergunta: str, limite: int) -> list[Trecho]:
        return self._trechos[:limite]

"""Cliente de LLM roteirizado para testar o Zétele sem rede."""

import copy
import json
from dataclasses import dataclass, field
from typing import Any


@dataclass
class Bloco:
    type: str
    text: str = ""
    id: str = ""
    name: str = ""
    input: dict[str, Any] = field(default_factory=dict)


@dataclass
class Uso:
    input_tokens: int = 10
    output_tokens: int = 5
    cache_read_input_tokens: int = 0
    cache_creation_input_tokens: int = 0


@dataclass
class RespostaFalsa:
    stop_reason: str
    content: list[Bloco]
    usage: Uso = field(default_factory=Uso)


class ClienteLLMFalso:
    def __init__(self, roteiro: list[RespostaFalsa | Exception]) -> None:
        self.roteiro = list(roteiro)
        self.pedidos: list[dict[str, Any]] = []

    def criar(self, **kwargs: Any) -> RespostaFalsa:
        self.pedidos.append(copy.deepcopy(kwargs))
        item = self.roteiro.pop(0)
        if isinstance(item, Exception):
            raise item
        return item


def final(tipo: str, texto: str, sugestoes: tuple[str, ...] = ()) -> RespostaFalsa:
    corpo = json.dumps({"tipo": tipo, "texto": texto, "sugestoes": list(sugestoes)}, ensure_ascii=False)
    return RespostaFalsa("end_turn", [Bloco("text", text=corpo)])


def ferramenta(nome: str, entrada: dict[str, Any], id: str = "t1") -> RespostaFalsa:
    return RespostaFalsa("tool_use", [Bloco("tool_use", id=id, name=nome, input=entrada)])

"""Única peça que conhece o SDK da Anthropic. O agente só vê ClienteLLM."""

from typing import Any, Protocol

import anthropic

FORMATO: dict[str, Any] = {
    "type": "json_schema",
    "schema": {
        "type": "object",
        "properties": {
            "tipo": {"type": "string", "enum": ["resposta", "recusa", "sem_informacao"]},
            "texto": {"type": "string"},
            "sugestoes": {"type": "array", "items": {"type": "string"}},
        },
        "required": ["tipo", "texto", "sugestoes"],
        "additionalProperties": False,
    },
}


class TempoEsgotado(Exception):
    """A chamada passou do timeout do cliente."""


class ProvedorIndisponivel(Exception):
    """Anthropic fora, sem crédito, limite de taxa ou erro de rede: o Zétele descansa um pouco."""


class ClienteLLM(Protocol):
    def criar(
        self,
        *,
        system: list[dict[str, Any]],
        messages: list[dict[str, Any]],
        tools: list[dict[str, Any]],
        ultima_rodada: bool,
    ) -> Any: ...


class ClienteAnthropic:
    def __init__(self, chave: str, modelo: str) -> None:
        self._cliente = anthropic.Anthropic(api_key=chave, timeout=20.0, max_retries=1)
        self._modelo = modelo

    def criar(
        self,
        *,
        system: list[dict[str, Any]],
        messages: list[dict[str, Any]],
        tools: list[dict[str, Any]],
        ultima_rodada: bool,
    ) -> Any:
        parametros: dict[str, Any] = {
            "model": self._modelo,
            "max_tokens": 1500,
            "system": system,
            "messages": messages,
            "tools": tools,
            # Sonnet 5.5 recusa tool_choice any/tool (400); na última rodada, "none" força a resposta
            "tool_choice": {"type": "none"} if ultima_rodada else {"type": "auto"},
            "thinking": {"type": "adaptive"},
            "output_config": {"effort": "low", "format": FORMATO},
            "betas": ["server-side-fallback-2026-07-01"],
            "extra_body": {"fallbacks": "default"},
        }
        try:
            return self._cliente.beta.messages.create(**parametros)
        except anthropic.APITimeoutError as exc:
            raise TempoEsgotado from exc
        except anthropic.RateLimitError as exc:
            raise ProvedorIndisponivel("limite de taxa da Anthropic") from exc
        except anthropic.APIStatusError as exc:
            raise ProvedorIndisponivel(f"HTTP {exc.status_code}") from exc
        except anthropic.APIConnectionError as exc:
            raise ProvedorIndisponivel("falha de conexão") from exc

```python
"""Laço do Zétele: ferramentas → resposta → conferência → reserva determinística (ADR 0029)."""

import json
import logging
import time
from collections.abc import Callable
from dataclasses import dataclass, field
from typing import Any

from zetele import ferramentas, prompt, verificacao
from zetele.cliente import ClienteLLM, TempoEsgotado
from zetele.conhecimento import texto_da_base
from zetele.ferramentas import ResultadoFerramenta

log = logging.getLogger(__name__)

MAX_RODADAS = 3
MAX_CHAMADAS = 4
ORCAMENTO_SEGUNDOS = 40.0
MAX_HISTORICO = 6

TEXTO_RECUSA = "Isso eu não sei responder. Posso ajudar com o Painel, o Observatório ou as páginas da FAPERON."
TEXTO_DEMORA = "Demorei demais para consultar os dados. Tente de novo ou abra o Painel Agro Analítico."
TEXTO_SEM_CONFIRMACAO = "Não consegui confirmar essa informação. Para números, use o Painel Agro Analítico."


@dataclass(frozen=True)
class Resposta:
    status: str
    texto: str
    fontes: list[dict[str, Any]] = field(default_factory=list)
    sugestoes: list[str] = field(default_factory=list)
    tokens_entrada: int = 0
    tokens_saida: int = 0


class _Abortar(Exception):
    """Erro inesperado numa ferramenta: não é culpa do modelo, vai para a reserva."""


def _mensagens(historico: list[dict[str, str]], pergunta: str, pagina: str) -> list[dict[str, Any]]:
    """A API exige começar pelo usuário e alternar papéis: descarta o que sobra e junta repetidos."""
    msgs: list[dict[str, Any]] = []
    for item in historico[-MAX_HISTORICO:]:
        papel = "user" if item["papel"] == "visitante" else "assistant"
        if not msgs and papel == "assistant":
            continue
        if msgs and msgs[-1]["role"] == papel:
            msgs[-1]["content"] += "\n\n" + item["texto"]
        else:
            msgs.append({"role": papel, "content": item["texto"]})
    atual = f"(O visitante está em {pagina}.)\n\n{pergunta}"
    if msgs and msgs[-1]["role"] == "user":
        msgs[-1]["content"] += "\n\n" + atual
    else:
        msgs.append({"role": "user", "content": atual})
    return msgs


def _ler_final(resposta: Any) -> tuple[str, str, list[str]]:
    texto = "".join(b.text for b in resposta.content if getattr(b, "type", None) == "text").strip()
    try:
        corpo = json.loads(texto)
        sugestoes = [str(s).strip()[:120] for s in corpo.get("sugestoes", []) if str(s).strip()][:2]
        return str(corpo["tipo"]), str(corpo["texto"]).strip(), sugestoes
    except (ValueError, KeyError, TypeError, AttributeError):
        if texto.startswith("[RECUSA]"):
            return "recusa", texto.removeprefix("[RECUSA]").strip(), []
        return "resposta", texto, []


def _fontes(resultados: list[ResultadoFerramenta]) -> list[dict[str, Any]]:
    vistas: set[tuple[str, str | None]] = set()
    saida: list[dict[str, Any]] = []
    for r in resultados:
        for f in r.fontes:
            chave = (f["url_fonte"], f["url_interna"])
            if chave not in vistas:
                vistas.add(chave)
                saida.append(f)
    return saida


def _executar(uso: Any, n: int, resultados: list[ResultadoFerramenta]) -> dict[str, Any]:
    base = {"type": "tool_result", "tool_use_id": uso.id}
    if n > MAX_CHAMADAS:
        return {**base, "content": "Limite de consultas desta pergunta atingido. Responda com o que já tem.", "is_error": True}
    try:
        res = ferramentas.executar(uso.name, dict(uso.input))
    except ferramentas.ErroDeFerramenta as exc:
        return {**base, "content": str(exc), "is_error": True}
    except Exception as exc:
        log.exception("zetele: ferramenta %s falhou", uso.name)
        raise _Abortar from exc
    resultados.append(res)
    return {**base, "content": json.dumps(res.dados, ensure_ascii=False, default=str)}


def responder(
    cliente: ClienteLLM,
    pergunta: str,
    historico: list[dict[str, str]],
    pagina: str,
    *,
    relogio: Callable[[], float] = time.monotonic,
) -> Resposta:
    inicio = relogio()
    system = prompt.system_atual()
    messages = _mensagens(historico, pergunta, pagina)
    resultados: list[ResultadoFerramenta] = []
    tokens = [0, 0]
    chamadas = 0

    def reserva(status: str, padrao: str) -> Resposta:
        texto = " ".join(r.resumo for r in resultados[:2]) if resultados else padrao
        return Resposta(status, texto, _fontes(resultados), [], tokens[0], tokens[1])

    for rodada in range(MAX_RODADAS):
        if relogio() - inicio > ORCAMENTO_SEGUNDOS:
            return reserva("erro", TEXTO_DEMORA)
        try:
            r = cliente.criar(
                system=system,
                messages=messages,
                tools=ferramentas.DEFINICOES,
                ultima_rodada=rodada == MAX_RODADAS - 1,
            )
        except TempoEsgotado:
            return reserva("erro", TEXTO_DEMORA)
        uso_tokens = r.usage
        tokens[0] += (
            uso_tokens.input_tokens
            + (uso_tokens.cache_read_input_tokens or 0)
            + (uso_tokens.cache_creation_input_tokens or 0)
        )
        tokens[1] += uso_tokens.output_tokens
        if r.stop_reason == "refusal":
            return Resposta("recusada", TEXTO_RECUSA, [], [], tokens[0], tokens[1])
        usos = [b for b in r.content if getattr(b, "type", None) == "tool_use"]
        if r.stop_reason == "tool_use" and usos:
            # só acréscimo: o content volta inteiro (thinking incluído), sem edição
            messages.append({"role": "assistant", "content": r.content})
            blocos = []
            try:
                for uso in usos:
                    chamadas += 1
                    blocos.append(_executar(uso, chamadas, resultados))
            except _Abortar:
                return reserva("erro", TEXTO_SEM_CONFIRMACAO)
            messages.append({"role": "user", "content": blocos})
            continue
        tipo, texto, sugestoes = _ler_final(r)
        if tipo == "recusa":
            return Resposta("recusada", texto or TEXTO_RECUSA, [], sugestoes, tokens[0], tokens[1])
        v = verificacao.verificar(
            texto,
            dados=[res.dados for res in resultados],
            referencias=[texto_da_base(), pergunta, *(h["texto"] for h in historico)],
            urls_ferramentas=set().union(*(res.urls for res in resultados)),
        )
        if v.links_removidos:
            log.info("zetele: %s link(s) removido(s) da resposta", v.links_removidos)
        if not v.aprovada or not v.texto:
            log.warning("zetele: conferência reprovou a resposta: %s", "; ".join(v.motivos))
            return reserva("verificacao_falhou", TEXTO_SEM_CONFIRMACAO)
        return Resposta("respondida", v.texto, _fontes(resultados), sugestoes, tokens[0], tokens[1])
    return reserva("verificacao_falhou", TEXTO_SEM_CONFIRMACAO)
```

"""Se o Zétele pode chamar o modelo agora: chave, disjuntor e orçamento do dia."""

from typing import Any

from django.conf import settings
from django.core.cache import cache
from django.utils import timezone

CHAVE_DISJUNTOR = "zetele:disjuntor"
DISJUNTOR_SEGUNDOS = 120


def _chave_dia() -> str:
    return f"zetele:dia:{timezone.localdate().isoformat()}"


def perguntas_hoje() -> int:
    return int(cache.get(_chave_dia(), 0))


def contar_pergunta() -> int:
    chave = _chave_dia()
    cache.add(chave, 0, timeout=2 * 86400)
    return int(cache.incr(chave))


def abrir_disjuntor() -> None:
    """Anthropic falhou: 2 minutos sem tentar, para não prender threads do gunicorn."""
    cache.set(CHAVE_DISJUNTOR, True, timeout=DISJUNTOR_SEGUNDOS)


def estado() -> dict[str, Any]:
    if not settings.ANTHROPIC_API_KEY:
        return {"disponivel": False, "motivo": "sem_chave"}
    if cache.get(CHAVE_DISJUNTOR):
        return {"disponivel": False, "motivo": "indisponivel"}
    if perguntas_hoje() >= settings.ZETELE_LIMITE_DIARIO:
        return {"disponivel": False, "motivo": "orcamento_diario"}

import logging
import threading
from typing import Any, cast

from django.conf import settings
from drf_spectacular.utils import extend_schema
from rest_framework import serializers
from rest_framework.request import Request
from rest_framework.response import Response
from rest_framework.throttling import ScopedRateThrottle
from rest_framework.views import APIView

from zetele import agente, disponibilidade, registro
from zetele.cliente import ClienteAnthropic, ClienteLLM, ProvedorIndisponivel
from zetele.models import Pergunta
from zetele.throttles import ZeteleGlobalThrottle

log = logging.getLogger(__name__)

PAGINAS_COM_ZETELE = ("/", "/central-de-inteligencia", "/central-de-inteligencia/observatorio", "/painel")
# Uma pergunta prende uma thread do gunicorn por até 40 s: no máximo N por processo (ADR 0025).
SEMAFORO = threading.BoundedSemaphore(settings.ZETELE_SIMULTANEOS)
MENSAGENS = {
    "sem_chave": "O assistente está desligado; use as perguntas prontas.",
    "orcamento_diario": "O assistente atingiu o limite de hoje; use as perguntas prontas.",
    "indisponivel": "O assistente está indisponível no momento; tente de novo em instantes.",
    "ocupado": "O assistente está atendendo muitas pessoas; tente de novo em instantes.",
}
RETRY = {"sem_chave": 3600, "orcamento_diario": 3600, "indisponivel": 60, "ocupado": 10}


def obter_cliente() -> ClienteLLM:
    return ClienteAnthropic(settings.ANTHROPIC_API_KEY, settings.ZETELE_MODELO)


class MensagemSerializer(serializers.Serializer):
    papel = serializers.ChoiceField(choices=["visitante", "zetele"])
    texto = serializers.CharField(max_length=1200)


class PerguntaSerializer(serializers.Serializer):
    pergunta = serializers.CharField(max_length=500)
    historico = MensagemSerializer(many=True, required=False, default=list)
    pagina = serializers.ChoiceField(choices=PAGINAS_COM_ZETELE)

    def validate_historico(self, valor: list[dict[str, str]]) -> list[dict[str, str]]:
        if len(valor) > 6:
            raise serializers.ValidationError("No máximo 6 mensagens.")
        return valor


class EstadoSerializer(serializers.Serializer):
    disponivel = serializers.BooleanField()
    motivo = serializers.CharField(allow_null=True)


class FonteSerializer(serializers.Serializer):
    rotulo = serializers.CharField()
    url_fonte = serializers.CharField()
    url_interna = serializers.CharField(allow_null=True)
    atualizado_em = serializers.CharField(allow_null=True)


class RespostaSerializer(serializers.Serializer):
    status = serializers.ChoiceField(choices=["respondida", "recusada", "erro"])
    texto = serializers.CharField()
    fontes = FonteSerializer(many=True)
    sugestoes = serializers.ListField(child=serializers.CharField())


def _indisponivel(motivo: str) -> Response:
    r = Response({"erro": MENSAGENS[motivo], "motivo": motivo}, status=503)
    r["Retry-After"] = str(RETRY[motivo])
    return r


class EstadoView(APIView):
    @extend_schema(responses={200: EstadoSerializer})
    def get(self, request: Request) -> Response:
        return Response(disponibilidade.estado())


class PerguntarView(APIView):
    throttle_classes = [ScopedRateThrottle, ZeteleGlobalThrottle]
    throttle_scope = "zetele"

    def check_throttles(self, request: Request) -> None:
        """Para no primeiro limite que recusa: pedido barrado por IP não gasta o teto global."""
        for throttle in self.get_throttles():
            if not throttle.allow_request(request, self):
                self.throttled(request, cast(float, throttle.wait()))

    @extend_schema(request=PerguntaSerializer, responses={200: RespostaSerializer})
    def post(self, request: Request) -> Response:
        entrada = PerguntaSerializer(data=request.data)
        entrada.is_valid(raise_exception=True)
        d: dict[str, Any] = dict(entrada.validated_data)
        pergunta, pagina = d["pergunta"], d["pagina"]
        historico = [dict(m) for m in d["historico"]]

        situacao = disponibilidade.estado()
        if not situacao["disponivel"]:
            registro.registrar(pergunta, Pergunta.Status.INDISPONIVEL, pagina)
            return _indisponivel(situacao["motivo"])
        if disponibilidade.contar_pergunta() > settings.ZETELE_LIMITE_DIARIO:
            registro.registrar(pergunta, Pergunta.Status.INDISPONIVEL, pagina)
            return _indisponivel("orcamento_diario")
        if not SEMAFORO.acquire(blocking=False):
            return _indisponivel("ocupado")
        try:
            resposta = agente.responder(obter_cliente(), pergunta, historico, pagina)
        except ProvedorIndisponivel as exc:
            log.warning("zetele: provedor indisponível (%s)", exc)
            disponibilidade.abrir_disjuntor()
            registro.registrar(pergunta, Pergunta.Status.ERRO, pagina)
            return _indisponivel("indisponivel")
        finally:
            SEMAFORO.release()

        registro.registrar(
            pergunta, resposta.status, pagina, resposta.tokens_entrada, resposta.tokens_saida
        )
        # a reserva determinística é uma resposta válida: o visitante não precisa saber da falha
        status = "respondida" if resposta.status == "verificacao_falhou" else resposta.status
        return Response(
            {"status": status, "texto": resposta.texto, "fontes": resposta.fontes, "sugestoes": resposta.sugestoes}
        )
```

import type { PaginaComZetele } from "@/content/zetele";
import { API_BASE } from "./api";

export interface FonteZetele {
  rotulo: string;
  url_fonte: string;
  url_interna: string | null;
  atualizado_em: string | null;
}

export interface RespostaZetele {
  status: "respondida" | "recusada" | "erro";
  texto: string;
  fontes: FonteZetele[];
  sugestoes: string[];
}

export interface EstadoZetele {
  disponivel: boolean;
  motivo: string | null;
}

export interface MensagemHistorico {
  papel: "visitante" | "zetele";
  texto: string;
}

export type ResultadoPergunta =
  | { tipo: "ok"; resposta: RespostaZetele }
  | { tipo: "espera"; segundos: number }
  | { tipo: "indisponivel"; motivo: string }
  | { tipo: "falha" };

const BASE = `${API_BASE}/zetele`;
const MAX_HISTORICO = 6;

export async function obterEstado(): Promise<EstadoZetele> {
  try {
    const r = await fetch(`${BASE}/estado`, { cache: "no-store" });
    if (!r.ok) return { disponivel: false, motivo: "indisponivel" };
    return (await r.json()) as EstadoZetele;
  } catch {
    return { disponivel: false, motivo: "indisponivel" };
  }
}

export async function perguntar(
  pergunta: string,
  historico: MensagemHistorico[],
  pagina: PaginaComZetele,
): Promise<ResultadoPergunta> {
  try {
    const r = await fetch(`${BASE}/perguntar`, {
      method: "POST",
      headers: { "content-type": "application/json" },
      body: JSON.stringify({ pergunta, historico: historico.slice(-MAX_HISTORICO), pagina }),
    });
    if (r.ok) return { tipo: "ok", resposta: (await r.json()) as RespostaZetele };
    if (r.status === 429) return { tipo: "espera", segundos: Number.parseInt(r.headers.get("retry-after") ?? "", 10) || 30 };
    if (r.status === 503) {
      const corpo = (await r.json().catch(() => ({}))) as { motivo?: string };
      return { tipo: "indisponivel", motivo: corpo.motivo ?? "indisponivel" };
    }
    return { tipo: "falha" };
  } catch {
    return { tipo: "falha" };
  }
}

export type ParteTexto = { tipo: "texto"; texto: string } | { tipo: "link"; texto: string; href: string };

const RE_LINK = /\[([^\]]+)\]\(([^)\s]+)\)/g;

/** O servidor já conferiu os links; aqui só se transforma Markdown em partes, aceitando rota interna ou https. */
export function partesDoTexto(texto: string): ParteTexto[] {
  const partes: ParteTexto[] = [];
  let ultimo = 0;
  for (const m of texto.matchAll(RE_LINK)) {
    const href = m[2]!;
    if (!href.startsWith("/") && !href.startsWith("https://")) continue;
    if (m.index! > ultimo) partes.push({ tipo: "texto", texto: texto.slice(ultimo, m.index) });
    partes.push({ tipo: "link", texto: m[1]!, href });
    ultimo = m.index! + m[0].length;
  }
  if (ultimo < texto.length) partes.push({ tipo: "texto", texto: texto.slice(ultimo) });
  return partes;
}

"""Recorta as 3 poses do Zétele da arte original, remove o fundo e grava em public/zetele/.

Uso (raiz do repo):
  uv run --with pillow --with "rembg[cpu]" python apps/web/scripts/recortar-zetele.py ARTE.jpeg
A arte original tem 2752x1536; as caixas abaixo isolam cada pose sem os enfeites (folhas, trator).
"""

import sys
from pathlib import Path

from PIL import Image
from rembg import remove

CAIXAS = {
    "acenando": (200, 70, 1000, 1510),
    "tablet": (1090, 70, 1720, 1510),
    "apontando": (1800, 70, 2575, 1510),
}
LARGURA = 320
LIMITE_BYTES = 60_000
DESTINO = Path(__file__).resolve().parent.parent / "public" / "zetele"


def main(arte: Path) -> None:
    DESTINO.mkdir(parents=True, exist_ok=True)
    original = Image.open(arte).convert("RGB")
    for nome, caixa in CAIXAS.items():
        recorte = remove(original.crop(caixa))
        assert isinstance(recorte, Image.Image)
        recorte = recorte.crop(recorte.getbbox())
        altura = round(recorte.height * LARGURA / recorte.width)
        final = recorte.resize((LARGURA, altura), Image.Resampling.LANCZOS)
        png = DESTINO / f"{nome}.png"
        final.save(png, optimize=True)
        tamanho = png.stat().st_size
        if tamanho > LIMITE_BYTES:
            webp = DESTINO / f"{nome}.webp"
            final.save(webp, quality=85, method=6)
            print(f"{nome}: PNG com {tamanho} B passou do teto; WebP com {webp.stat().st_size} B")
        else:
            print(f"{nome}: {png.name} {final.size} {tamanho} B")


if __name__ == "__main__":
    main(Path(sys.argv[1]))
```

import { X } from "lucide-react";
import { useEffect, useState } from "react";
import { ZETELE } from "@/content/zetele";

export const CHAVE_SAUDACAO = "zetele-saudou";

/** Sem storage (aba privada, bloqueio) o balão aparece; o X continua fechando na página atual. */
function foiDispensada(): boolean {
  try {
    return window.sessionStorage.getItem(CHAVE_SAUDACAO) === "1";
  } catch {
    return false;
  }
}

export function marcarSaudou(): void {
  try {
    window.sessionStorage.setItem(CHAVE_SAUDACAO, "1");
  } catch {
    // sem storage: o balão volta na próxima página, o que é aceitável
  }
}

/** Balão fixo ao lado do Zétele: aparece ao carregar e fica até ser clicado ou fechado. */
export function SaudacaoZetele({ bloqueada, onAbrir }: { bloqueada: boolean; onAbrir: () => void }) {
  // começa escondido e decide no efeito: o sessionStorage não existe no servidor (evita erro de hidratação)
  const [visivel, setVisivel] = useState(false);

  useEffect(() => {
    setVisivel(!bloqueada && !foiDispensada());
  }, [bloqueada]);

  function dispensar() {
    marcarSaudou();
    setVisivel(false);
  }

  if (!visivel) return null;
  return (
    <div
      role="status"
      className="zetele-balao mb-24 flex items-center gap-1 rounded-2xl rounded-br-sm border border-line bg-card py-1.5 pl-4 pr-1.5 text-sm text-ink shadow-lg"
    >
      <button
        type="button"
        onClick={() => {
          dispensar();
          onAbrir();
        }}
        className="font-medium text-brand-fg underline-offset-2 hover:underline"
      >
        {ZETELE.saudacao}
      </button>
      <button
        type="button"
        aria-label={ZETELE.rotuloFecharSaudacao}
        onClick={dispensar}

        <X aria-hidden="true" className="h-4 w-4" />

    </div>
  );
}

export function Chips({ visiveis, demais, soEstaticas, onEscolher }: Props) {
  const [todas, setTodas] = useState(false);

  return (

import { useEffect, useRef, useState } from "react";

  perguntasDaPagina,

 *  Fica fixo no canto inferior direito (acompanha a rolagem), com o balão de saudação à esquerda. */
export function Zetele() {
  const caminho = usePathname();
  if (!ehPaginaComZetele(caminho)) return null;
  return <ZeteleNaPagina pagina={caminho} />;

function ZeteleNaPagina({ pagina }: { pagina: PaginaComZetele }) {
  const [aberto, setAberto] = useState(false);
  const [mensagens, setMensagens] = useState<Mensagem[]>([]);
  const [carregando, setCarregando] = useState(false);
  const [disponivel, setDisponivel] = useState(true);
  const [espera, setEspera] = useState(0);
  const [pose, setPose] = useState<Pose>("acenando");
  const [mostrarChips, setMostrarChips] = useState(true);
  const [sugeridas, setSugeridas] = useState<PerguntaPronta[]>([]);
  const botaoRef = useRef<HTMLButtonElement>(null);
  const campoRef = useRef<HTMLTextAreaElement>(null);
  const fecharRef = useRef<HTMLButtonElement>(null);
  const proximoId = useRef(1);

  useEffect(() => {
    let vivo = true;
    void obterEstado().then((e) => {
      if (vivo) setDisponivel(e.disponivel);
    });
    return () => {
      vivo = false;
    };
  }, []);

  useEffect(() => {
    if (espera <= 0) return;
    const t = window.setTimeout(() => setEspera((s) => s - 1), 1000);
    return () => window.clearTimeout(t);
  }, [espera]);

  useEffect(() => {
    if (!aberto) return;
    if (campoRef.current && !campoRef.current.disabled) campoRef.current.focus();
    else fecharRef.current?.focus();
  }, [aberto, disponivel]);

  const adicionar = (m: Omit<Mensagem, "id">) => setMensagens((lista) => [...lista, { ...m, id: proximoId.current++ }]);

  function abrir() {
    marcarSaudou();
    setAberto(true);
  }

  function fechar() {
    setAberto(false);
    botaoRef.current?.focus();
  }

  async function enviarPergunta(texto: string) {
    const historico: MensagemHistorico[] = mensagens
      .filter((m) => !m.perguntaOriginal)
      .map((m) => ({ papel: m.autor, texto: m.texto }));
    adicionar({ autor: "visitante", texto });
    setMostrarChips(false);
    setSugeridas([]);
    setCarregando(true);
    setPose("tablet");
    const r = await perguntar(texto, historico, pagina);
    setCarregando(false);
    if (r.tipo === "ok") {
      const { resposta } = r;
      adicionar({ autor: "zetele", texto: resposta.texto, fontes: resposta.fontes });
      const temLink = resposta.fontes.length > 0 || resposta.texto.includes("](");
      setPose(temLink || resposta.status === "recusada" ? "apontando" : "acenando");
      if (resposta.sugestoes.length) {
        setSugeridas(resposta.sugestoes.map((s, i) => ({ id: `sugestao-${i}`, texto: s, tipo: "dados" })));
        setMostrarChips(true);
      }
      return;
    }
    setPose("acenando");
    if (r.tipo === "espera") {
      setEspera(r.segundos);
      adicionar({ autor: "zetele", texto: ZETELE.espera(r.segundos) });
    } else if (r.tipo === "indisponivel") {
      // sem chave ou orçamento do dia: só perguntas prontas até recarregar; fora do ar ou ocupado: só avisa
      if (r.motivo === "sem_chave" || r.motivo === "orcamento_diario") setDisponivel(false);
      adicionar({ autor: "zetele", texto: ZETELE.descansando });
      setMostrarChips(true);
    } else {
      adicionar({ autor: "zetele", texto: ZETELE.falha, perguntaOriginal: texto });
    }
  }

  function escolher(p: PerguntaPronta) {
    if (p.tipo === "estatica") {
      adicionar({ autor: "visitante", texto: p.texto });
      adicionar({
        autor: "zetele",
        texto: p.resposta ?? "",
        link: p.href ? { href: p.href, rotulo: p.rotuloLink ?? p.href } : undefined,
      });
      setPose(p.href ? "apontando" : "acenando");
      setMostrarChips(false);
      return;
    }
    void enviarPergunta(p.texto);
  }

  const daPagina = perguntasDaPagina(pagina);
  const visiveis = sugeridas.length ? sugeridas : daPagina.visiveis;
  const demais = sugeridas.length ? [] : daPagina.demais;

  return (
    <>
      <div
        className="pointer-events-none fixed bottom-4 right-4 z-30 flex items-end gap-2"
        style={{ paddingBottom: "env(safe-area-inset-bottom)" }}
      >
        <div className="pointer-events-auto">
          <SaudacaoZetele bloqueada={aberto} onAbrir={abrir} />
        </div>
        <div className="pointer-events-auto">
          <BotaoZetele ref={botaoRef} aberto={aberto} pose={pose} onClick={() => (aberto ? fechar() : abrir())} />
        </div>
      </div>
      {aberto && (
        <PainelZetele
          pose={pose}
          mensagens={mensagens}
          carregando={carregando}
          disponivel={disponivel}
          espera={espera}
          mostrarChips={mostrarChips}
          visiveis={visiveis}
          demais={demais}
          campoRef={campoRef}
          fecharRef={fecharRef}
          onFechar={fechar}
          onEnviar={(t) => void enviarPergunta(t)}
          onEscolher={escolher}
          onMostrarChips={() => setMostrarChips(true)}
        />
      )}
    </>
  );
}

```markdown
# ADR 0029: Zétele, assistente com LLM restrito ao site e números conferidos em código

Status: Aceita

## Contexto

O site precisa de um assistente que explique onde está cada recurso e como usar a Central de Inteligência, e que responda perguntas com números do IBGE que o próprio site publica. A ADR 0007 proíbe texto gerado por LLM no que a FAPERON publica, porque esse texto precisa ser reprodutível e auditável.

## Opções

- **Escolhida:** backend no Django com o SDK Python da Anthropic (Claude Sonnet 5.5), laço manual de ferramentas sobre os serviços determinísticos, base de conhecimento inteira no system prompt com prompt caching, resposta inteira (sem streaming), conferência em código antes de entregar.
- **Descartadas:** Route Handler no Next.js (a chave ficaria no container exposto pelo Funnel e as ferramentas gastariam o limite `anon` por HTTP); RAG já nesta entrega (o conteúdo do site cabe no prompt; embeddings e reindexação sem necessidade); streaming (não permite conferir o texto antes de mostrá-lo).

## Decisão

- O Zétele só responde sobre o site. Fora disso, recusa em uma frase.
- Números vêm só das ferramentas `ranking_municipios`, `evolucao_e_analise` e `bloco_observatorio`, que chamam as mesmas funções do Painel e do Observatório.
- Antes de entregar, `zetele/verificacao.py` exige que todo número do texto exista nos resultados das ferramentas, na base ou na conversa; remove links fora da lista; reprova palavras em inglês e termos bloqueados.
- Se a conferência reprova, a resposta do modelo é descartada e vai uma frase determinística montada a partir do resultado da ferramenta.
- As fontes (IBGE, tabela, ano, link para a consulta equivalente no Painel ou no Observatório) são montadas pelo servidor, nunca pelo modelo.
- Limites: 6/min por IP, 30/min global, 1.500 perguntas por dia, 3 simultâneas por processo, 40 s por pergunta. Sem chave ou sem orçamento, o widget mostra só as perguntas prontas.
- A chave fica em `.env.local`, lido só pelo container `api`.

## Relação com a ADR 0007

A 0007 continua valendo para todo texto publicado (análise, Observatório, PDF). O Zétele não publica: conversa. Mesmo assim, o LLM só escolhe a ferramenta e redige a ligação entre as partes; todo número sai de uma função determinística já testada, é conferido literalmente e vem com o link da consulta onde o visitante vê o mesmo número. Quando a conferência falha, o texto volta a ser determinístico.

## Consequências

- Custo variável por pergunta (cerca de US$ 0,01 com o prompt em cache) e dependência de um fornecedor externo; o teto diário e o modo degradado limitam os dois.
- O RAG futuro entra pela interface `FonteDeConhecimento` (pgvector no Postgres existente) sem mexer no agente.
- Antes de mudar prompt, base ou modelo, rodar as perguntas de ouro (`pytest -m llm`).
```

# ADR 0030: Registro anônimo das perguntas do Zétele por 90 dias

Status: Aceita

## Contexto

Para montar o FAQ e melhorar as respostas, é útil saber o que os visitantes perguntam. A política de privacidade descreve só o que o site faz e o site não guarda dados pessoais de quem consulta o painel.

## Opções

## Consequências

- Base legal proposta: legítimo interesse (art. 7º, IX), com dado anonimizado na origem. O deploy depende do ciente do encarregado (registrado em `docs/erros-conhecidos/em-aberto.md`).

Expected: estado `{"disponivel": true, ...}`; a pergunta volta com `status: respondida`, um número com fonte e `url_interna` do Painel.
