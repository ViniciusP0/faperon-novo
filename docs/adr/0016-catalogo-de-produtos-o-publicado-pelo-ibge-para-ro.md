# ADR 0016: Catálogo de produtos = o publicado pelo IBGE para RO

Status: Aceita

## Contexto

A expectativa inicial de 89 produtos não bate com os cerca de 70 da tabela 5457.

## Opções

- **Escolhida:** Catálogo de produtos = o publicado pelo IBGE para RO
- **Descartadas:** Lista curada; juntar tabelas de safra

## Decisão

O catálogo exibido é o que o IBGE publica para Rondônia nas tabelas 5457, 3939 e 74.

Motivo: Sem manutenção manual.

## Consequências

Sem lista mantida à mão. Custo: o número exibido pode diferir da expectativa inicial.
