# ADR 0002: Sair do Wix para plataforma própria

Status: Aceita

## Contexto

O site atual está no Wix e a Central de Inteligência exige painéis analíticos, geração de PDF e ingestão de dados que o Wix não suporta bem.

## Opções

- **Escolhida:** Sair do Wix para plataforma própria
- **Descartadas:** Manter Wix + iframe, Wix Velo

## Decisão

Migrar o site inteiro para uma plataforma própria depois do protótipo. O Wix segue no ar sem interrupção durante o protótipo.

Motivo: Gráficos, PDF, SEO e dados pesados não cabem no Wix.

## Consequências

Controle total de dados, SEO e performance. Custo: migração de conteúdo, redirects 301 e desligamento do Wix na Fase 2.
